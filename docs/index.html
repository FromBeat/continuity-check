  • The checker. It looks through one folder for the expected notes and prints a short wake-up card for each file that is there.
  • The change script. It prints what is newly present, newly missing, or different since the last look, and keeps that memory on the computer that runs it.
  • The line list. line.py prints one line from lines.txt, and anyone can replace the list.
