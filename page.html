Continuity check

Looks for the expected notes in one folder on this computer, then shows which are here, which are missing, and a short wake-up card.

Nothing is uploaded. The page only talks to the server on this same computer. Paste a full path, such as the folder you cloned plus examples/sample-shelf or examples/sample-shelf-full.

Pieces

  • check.py knows the filenames, the exit codes, and how to clip the wake-up card.
  • serve.py is a small local server. It calls those functions. It does not have its own copy of the rules.
  • This page is page.html. The button sends the two paths you typed.
  • A config file, when you give one, is JSON like {"files": ["IDENTITY.md", ...]}. Leave it blank to use the five default names.
